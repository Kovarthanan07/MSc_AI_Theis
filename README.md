# Towards Domain-General DeepFake Classification - A Dual-Branch Frequency and Spatial Approach with Few-Shot Adaptation

**Dissertation Project for MSc Artificial Intelligence**  
City St George’s, University of London

---

This repository contains the code and resources developed for my MSc dissertation:  
**Towards Domain-General DeepFake Classification: A Dual-Branch Frequency and Spatial Approach with Few-Shot Adaptation.**

The project explores a **dual-branch DeepFake detection framework**:
- **Frequency Branch**: Fast Fourier Transform (FFT) based features processed with ResNet-18.  
- **Spatial Branch**: Pretrained Swin Transformer for visual/spatial features.  
- **Fusion**: Cross-Attention & Concatenation mechanisms to combine features.  
- **Few-Shot Learning (FSL)**: Prototypical Networks for adaptation in low-data regimes.
